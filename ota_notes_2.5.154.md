# Vision+ 2.5.154 — «Inicio en la TV» con diagnóstico

**Si la tele se resistía, ahora se ve por qué**
- La pantalla muestra **«Detalles»**: cada comando enviado al televisor y lo que contestó.
- Cada paso tiene **tope de tiempo**: la app ya no se queda «pensando» para siempre.

**Y si falta el launcher, lo instala solo**
- Si el televisor no tiene Vision+ Home, el teléfono **lo instala por ADB** (el APK viaja dentro de la app) y continúa. Antes el flujo se detenía para no dejar la tele sin pantalla.

**Varias teles, cada una por separado**
- Lista de teles con su estado y **Aplicar / Restaurar / Olvidar** por televisor.
- **«Olvidar»** avisa si esa tele tiene cambios y ofrece **«Restaurar y olvidar»**.
- El teléfono reconoce cada tele por su identificador del sistema, no por la IP.

**Lo demás sigue igual**
- **«Aplicar»** reaplica sin pedir código y **«Restaurar»** devuelve esa tele como estaba.
- Candados: nunca desactiva Ajustes, System UI ni el instalador; no retira ningún Inicio sin tener Vision+ Home instalado.
