# Assignment review — 2026-10-09

Only 2 of the 40 original assignment tasks had any answer in the intersection.
Many paired mutually exclusive categories, making the third zone pointless.
The server now exclusively selects 60 bilingual tasks from `schaetzoramaAssignments.ts`,
expanded from the initial 24 by 36 additional tasks across geography, animals,
chemistry, astronomy, transport, everyday technology, sport, music and games.
The historical questions remain in the old content file for reference.

Each task contains 5–6 terms and correct answers in all three zones. The number
of overlapping terms varies between 1, 2 and 3. Terms are shuffled once per round,
and question history still prevents repeats throughout a ten-round session.
German and English prompts, category labels and term labels are supplied together.

Examples include input/output devices, strings/keyboards, mammals/egg laying,
botanical fruits/culinary vegetables, shared country borders, flag colours,
DNA/RNA bases and electricity/useful heat. Prompts explicitly constrain common
ambiguities: adult animals, mainland borders, ordinary instrument materials,
standard DNA/RNA bases, and useful heat rather than incidental waste heat.
Further examples include metals/liquids, planets/rings, moons/atmospheres,
renewable sources/electricity, rails/electric propulsion, team games/nets,
strings/plucking, and dice/cards. No two tasks reuse the same category pair.
Each task stays within 5–6 terms to preserve the existing host/phone layout.

Source references are stored with each task. Key references include the
[Australian Museum on mammals](https://australian.museum/learn/animals/mammals/),
[Philharmonia instrument guide](https://philharmonia.co.uk/resources/instruments/),
[Kew on tomatoes](https://www.kew.org/plants/tomato),
[CMAS underwater hockey rules](https://www.cmas.org/hockey/how-to-regulations.html),
[NASA on Solar System bodies](https://science.nasa.gov/learn/basics-of-space-flight/chapter1-2/),
and [NHGRI on DNA/RNA nucleotides](https://www.genome.gov/genetics-glossary/Nucleotide).
Additional references include [NASA on Chariklo's rings](https://science.nasa.gov/solar-system/asteroids/10199-chariklo/),
[NASA on Titan's atmosphere](https://science.nasa.gov/saturn/moons/titan/facts/),
[CATAN's base-game rules](https://www.catan.com/understand-catan/game-rules),
and [Hasbro's game instructions](https://instructions.hasbro.com/).
Country/flag references use the dated 2025 Factbook archive rather than implying
live political data. Future content changes still require editorial review;
structural tests cannot establish factual correctness.

Numeric and percentage controls now start at 0 rather than the range midpoint.
Public lower bounds and localized range titles now use 0, and the server accepts
that initial value. Authored internal lower bounds are retained for scoring so
the existing point tolerances do not widen, especially for year questions.
Solutions and maximum values are unchanged. Submitted answers remain visible.
