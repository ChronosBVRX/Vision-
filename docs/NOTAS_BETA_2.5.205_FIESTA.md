# Vision+ 2.5.205 — Beta Fiesta + Deportes

**Esta es una beta. No es OTA y no reemplaza la versión estable 2.5.204.**

## Deportes

- El selector de un partido ahora muestra **solo el nombre del canal y su formato**.
- Las señales que todavía no tienen dirección aparecen como **«Sin señal»**.
- La lista de canales se mantiene al día al abrir Deportes.

## Juegos: Vision+ Fiesta 3.0

Llegan seis juegos nuevos para jugar desde el teléfono y la tele:

- **La Última Palabra**
- **Vox Populi**
- **Fuera de Época**
- **Texto Roto**
- **Franela Fest**
- **El Tasador**

Incluye:

- Modo **Familiar** y modo **Sin filtro**.
- Una voz y personalidad nueva para cada juego.
- Preguntas, encuestas, escenas, camisetas y objetos originales.
- Sala por código/QR, tele compartida y teléfonos como controles.

## Cómo probar

1. Instala el APK de esta beta.
2. Abre **Vision+ → Juegos**.
3. Elige Familiar o Sin filtro.
4. La tele crea la sala; los teléfonos entran con el código o QR.

La app estable sigue disponible en la OTA normal. Esta beta se instala aparte
del canal estable y no cambia `/releases/latest`.
