# Referencias deportivas del launcher

Las fotos de `launcher/src/main/res/drawable-nodpi/sport_*.webp` son imágenes de referencia
para eventos sin portada propia. Se empaquetan en el APK para que el Inicio no dependa de la red
y se muestran detrás de la interfaz con un velo oscuro.

Origen: [Unsplash](https://unsplash.com), bajo la [Unsplash License](https://unsplash.com/license)
(uso comercial permitido, sin atribución obligatoria). Se recortaron a 1280×720 y se convirtieron
a WebP para reducir el tamaño del launcher.
