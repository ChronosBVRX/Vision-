# Vision+ 2.5.141 — BETA (canal de pruebas)

**Canal de pruebas separado del oficial**
- Esta release se publica como **pre-release** (tag fijo `beta`): GitHub no la ofrece en `/releases/latest`, así que **los usuarios normales no la ven**.
- Solo la reciben los equipos marcados desde el servidor (`beta_device_ids`). Se puede quitar o cambiar sin publicar nada.
- El actualizador, en un equipo de pruebas, compara beta y oficial y ofrece **la más nueva**: cuando una beta se convierte en oficial, el equipo de pruebas la recibe igual.

**Contenido de esta beta**
- El reintento rápido del reproductor de la 2.5.140 (10 s cuando el motor no recibió nada).
